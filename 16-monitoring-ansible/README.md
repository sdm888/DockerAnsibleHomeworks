# Решение ДЗ #1 по модулю 16

Плейбук Ansible, который включает следующие роли:
1. preconfig - устанавливает на удаленные сервера необходимые пакеты для работы с Docker;
2. swarm_init - инициализирует кластер Docker Swarm;
3. swarm_join - добавляет удаленные сервера в кластер в соответствии с их ролями;
4. prometheus - устанавливает и настраивает Prometheus как сервис Docker Swarm;
5. grafana - устанавливает и настраивает Grafana как сервис Docker Swarm;
6. alertmanager - устанавливает и настраивает Alert Manager как сервис Docker Swarm;

Конфиденциальные данные (имя и пароль администратора Grafana, а также данные для подключения к SMTP-серверу из Alert Manager) хранятся в зашифрованном файле group_vars/all/vault.yml. Для расшифровки используйте пароль "secret".

Для запуска нужно скопировать файл inventory.example.ini в файл inventory.ini, добавить туда реальные IP-адреса хостов и запустить плейбук командой:
```
ansible-playbook -i inventory.ini -J all.yml
```
При запуске плейбука понадобится ввести пароль для vault.
