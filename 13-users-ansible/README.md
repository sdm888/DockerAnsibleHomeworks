# Решение ДЗ по модулю 13

Плейбук Ansible, который включает роли "preconfig" и "users". Роль "preconfig" устанавливает на удаленные сервера  необходимые пакеты для работы с Docker. Роль "users" генерирует ключи SSH на локальном хосте, затем создает пользователей на удаленных хостах, копирует для них публичные ключи и добавляет пользователей в группу "docker".

Имена пользователей хранятся в файле group_vars/all/users.yml. Пароли пользователей в зашифрованном виде хранятся в файле group_vars/all/vault.yml. Для расшифровки используйте пароль "secret".

Для запуска нужно скопировать файл inventory.example.ini в файл inventory.ini, добавить туда список хостов и запустить плейбук командой:
```
ansible-playbook -i inventory.ini -J all.yml
```
При запуске плейбука понадобится ввести пароль для vault.
